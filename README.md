Instagram Clone

A responsive Instagram clone built using React and JSON Server.

Features:
- Home Feed
- Stories
- Suggested Users
- Follow / Unfollow
- Profile Page
- Edit Profile
- JSON Server Backend

Tech Stack:
- React
- React Router
- Bootstrap
- Axios
- JSON Server
- HTML
- CSS
- Javascript

Installation:

```bash
npm install
npm run dev
npx json-server --watch db/db.json --port 3000
